Frequently Asked Questions

Q: Where is configuration data localized?

A: All image assets, extracted DOM layouts, and process mapping logs remain strictly inside your browser instance's isolated container storage sandbox. Data structures are transmitted externally only to your selected LLM API endpoint for execution.

Q: Is a paid workspace premium registration mandatory?

A: No. ThinkKB functions as an independent operational layer utilizing your personal API endpoint tokens. Platforms like Google Gemini provide free developer usage tiers that maintain structural alignment perfectly with this client model.

Q: What is the purpose of the concluding screen capture flag?

A: The concluding processing state ensures that final operational validation records or "Success" confirmation frames are automatically preserved within the generated documentation history sequence.

Q: Does the utility interface universally across all internal target architectures?

A: The tool processes standard web interfaces fluidly. Specific proprietary intranet utilities enforcing strict Content Security Policies (CSP) or restrictive enterprise security headers may require explicit environmental override flags.
