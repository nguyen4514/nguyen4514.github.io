Configuration & Setup

To initialize the documentation engine, please configure your preferred AI provider:

1. API Credentials

ThinkKB processes contexts locally. Secure an authorized operational token from one of our supported infrastructure channels:

  • • Google Gemini: Get Gemini Key (Tiered options available)
  • • Groq Cloud: Get Groq Key
  • • OpenAI Developer: Get OpenAI Key
  • • Anthropic Console: Get Claude Key

2. Extension Linking

Access the ThinkKB settings dashboard panel inside your browser, supply your credential string within the matching provider section, and declare your default model target. Commit the changes to update the client configuration.
